# Prototype -> Android remake

The supplied `VOCODE2_AI_Helper_REVISED-2.html` already contained a working browser IDE foundation: editor tabs, HTML/CSS/JS files, an iframe runtime, console/problems views, folder import, project save/export, settings, a floating output screen, and an AI helper. The Android project keeps that functional direction but moves account/authentication, local database storage, file-picking, ZIP handling, terminal execution, notifications/background service and Shizuku integration to native Android.

The original file is preserved in `legacy/` rather than being thrown away.
